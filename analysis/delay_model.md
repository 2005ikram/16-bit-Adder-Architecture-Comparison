# Delay Model

## 1. Purpose

Propagation delay is one of the most important performance metrics in digital circuit design.

A digital circuit is not useful if it produces the correct output but requires too much time to do so. Therefore, digital designers analyze propagation delay to evaluate and improve circuit speed.

The objective of this chapter is to compare the propagation delay of two different 16-bit adder architectures:

- Ripple Carry Adder (RCA)
- Carry Lookahead Adder (CLA)

---

## 2. Propagation Delay

### Definition

Propagation delay is the time required for a change at the input of a logic gate to appear at its output.

### Physical Intuition

Although logic gates perform digital operations, they are physically built from transistors.

Every transistor introduces small parasitic capacitances. Before the output changes from logic 0 to logic 1 (or vice versa), these capacitances must charge or discharge.

This charging process requires a finite amount of time called the **propagation delay**, denoted by **τ (tau)**.

In real circuits, propagation delay depends on several factors:

- Gate type
- CMOS technology
- Fan-in
- Fan-out
- Load capacitance
- Routing delay

---

## 3. Why We Need a Timing Model

Modern digital circuits contain thousands or even millions of logic gates.

Computing the exact delay of every transistor is impractical during the early design stage.

Instead, engineers use simplified timing models that approximate the behavior of real hardware while remaining mathematically simple.

Common timing models include:

- Unit Delay Model
- RC Delay Model
- Library-Based Timing Model

This project uses the **Unit Delay Model**.

---

## 4. Unit Delay Model

### Assumption

Every logic gate has the same propagation delay.

Delay(gate) = τ

regardless of its type or number of inputs.

### Advantages

- Simple mathematical analysis
- Easy comparison between architectures
- Independent of fabrication technology

### Limitations

Real logic gates do not have identical delays.

Propagation delay depends on:

- Gate type
- Fan-in
- Fan-out
- Load capacitance
- Routing delay

Therefore, the Unit Delay Model predicts the **trend** of the delay rather than its exact physical value.

---

## 5. Arrival-Time Analysis

### 5.1 Arrival Time

Arrival time is a fundamental concept used in Static Timing Analysis (STA).

It represents the earliest time at which a signal is guaranteed to become stable and correct.

Primary inputs are assumed to be available at time zero.

Arrival(primary input) = 0

---

### 5.2 Arrival-Time Equation

The arrival time of any signal is computed using

Arrival(Output) = τ + max(Arrival(Inputs))

The **max** operator is used because a logic gate cannot produce a valid output until **all of its inputs have arrived**.

The slowest input determines when the gate can begin switching.

The longest signal path through the circuit is called the **critical path**.

---

## 6. General Delay Analysis Procedure

The propagation delay of any combinational circuit can be derived using the following procedure.

1. Write the Boolean equations.
2. Select a timing model.
3. Assign arrival times to the primary inputs.
4. Apply the arrival-time equation to every intermediate signal.
5. The propagation delay of the circuit is the maximum arrival time among all outputs.

This procedure can be applied to any combinational circuit.

---

## 7. Delay Analysis of Basic Building Blocks

### 7.1 Half Adder

#### Boolean Equations

Sum = A ⊕ B

Carry = A · B

#### Initial Conditions

Arrival(A) = 0

Arrival(B) = 0

#### Arrival-Time Calculation

Arrival(Sum) = τ + max(0, 0) = τ

Arrival(Carry) = τ + max(0, 0) = τ

Total Delay = τ

---

### 7.2 Full Adder

#### Boolean Equations

Generate = G = A · B

Propagate = P = A ⊕ B

Carry Out = Cout = G + P · Cin

Sum = P ⊕ Cin

#### Initial Conditions

Arrival(A) = 0

Arrival(B) = 0

Arrival(Cin) = 0

#### Arrival-Time Calculation

Arrival(G) = τ

Arrival(P) = τ

Arrival(Sum) = τ + max(τ, 0) = 2τ

Arrival(P · Cin) = τ + max(τ, 0) = 2τ

Arrival(Cout) = τ + max(τ, 2τ) = 3τ

Total Delay = 3τ

The carry output determines the critical path of the Full Adder.

---

## 8. Delay Analysis of the 16-bit Ripple Carry Adder

### Carry Equation

Ci+1 = Gi + Pi · Ci

where

Gi = Ai · Bi

Pi = Ai ⊕ Bi

#### Initial Conditions

Arrival(Ai) = 0

Arrival(Bi) = 0

Arrival(C0) = 0

Arrival(Gi) = τ

Arrival(Pi) = τ

#### Carry Arrival

Arrival(C1) = 3τ

Arrival(C2) = 5τ

Arrival(C3) = 7τ

Pattern:

Arrival(Cn) = (2n + 1)τ

For a 16-bit Ripple Carry Adder,

Arrival(C16) = 33τ

Therefore,

Total Delay = 33τ

The carry chain forms the critical path because every stage must wait for the carry generated by the previous stage.

---

## 9. Delay Analysis of the 16-bit Carry Lookahead Adder

### 9.1 Group Generate and Group Propagate

PG = P3 · P2 · P1 · P0

GG = G3 + P3G2 + P3P2G1 + P3P2P1G0

Arrival(PG) = τ + max(τ, τ, τ, τ) = 2τ

Arrival(GG) = τ + max(2τ, 2τ, 2τ, 2τ) = 3τ

---

### 9.2 Lookahead Carry Unit

C4 = GG0 + PG0 · Cin

Arrival(C4) = τ + max(3τ, 3τ) = 4τ

C8 = GG1 + PG1GG0 + PG1PG0Cin

Arrival(C8) = 5τ

C12 = GG2 + PG2GG1 + PG2PG1GG0 + PG2PG1PG0Cin

Arrival(C12) = 5τ

Arrival(C16) = 5τ

---

### 9.3 Local Carry Generation

Using the incoming carries generated by the Lookahead Carry Unit,

calculate

- C5
- C6
- C7
- C9
- C10
- C11
- C13
- C14
- C15

using the standard 4-bit CLA carry equations.

---

### 9.4 Total Delay

After calculating the local carries and the final sum outputs,

Total Delay = 8τ

Unlike the Ripple Carry Adder, carries are generated in parallel rather than propagating through all sixteen Full Adders.

---

## 10. RCA vs CLA

| Feature | Ripple Carry Adder | Carry Lookahead Adder |
|----------|--------------------|-----------------------|
| Total Delay | 33τ | 8τ |
| Critical Path | Carry Chain | Lookahead Logic |
| Delay Growth | O(n) | O(log n) |
| Carry Generation | Sequential | Parallel |

---

## 11. Limitations of the Unit Delay Model

The Unit Delay Model is a simplified timing model.

It does not consider:

- Different gate delays
- Fan-in effects
- Fan-out effects
- Routing delay
- Process variation
- FPGA or ASIC technology

Professional EDA tools perform Static Timing Analysis (STA) using technology libraries to obtain accurate timing values.

---

## 12. Key Takeaways

- Propagation delay is a fundamental performance metric in digital design.
- Arrival-time analysis provides a systematic method for calculating circuit delay.
- The Ripple Carry Adder has a linear delay because every carry depends on the previous stage.
- The Carry Lookahead Adder computes carries in parallel, significantly reducing the critical path.
- Although simplified, the Unit Delay Model correctly predicts how the delay scales with circuit size.
