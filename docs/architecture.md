# Architecture 
This projects implements and compares tw different 16-bit adder architecture:
-RCA and CLA 
Both architectures perform the addition of two 16-bit operands A and B with an input carry Cin and produce a 16-bit Sum and an output carry Cout .
## 1.16-bit Ripple Carry Adder (RCA)
The 16-bit Ripple Carry Adder is constructed by cascading 16 full adders.
The carry output of each full adder is connected to the carry input of the next stage.Therefore,the carry propagates sequentially from the least significant bit(LSB) to the most significant bit (MSB).
![16-bit RCA Architecture](figures/16-bit-RCA.drawio.png).
The main advantage of the Ripple Carry Adder is its simple and regular architecture.However,its propagation delay increases with the number of bits because each stage must wait for the carry generated by the previous stage.
## 2.4-bit Carry Look-Ahead Adder(CLA)
The Carry Look-Ahead Adder reduces carry propagation delay by calculating carries using propagate and generate signals.
For each bit:
Pi = Ai ^ Bi;
Gi = Ai & Bi;
The carry equations are derived from :
Ci+1 = Gi+PiCi;
For a 4-bit block ,the carry signals can therefore be determined without waiting for the carry to ripple through every full adder 
## 3.16-bit Carry Look-Ahead Adder 
The 16-bit CLA is implemented hierarchically using four 4-bit CLA blocks.
![16-bit CLA Architecture](figures/16-bit-CLA.drawio.png).
Each 4-bit CLA produces GP and GG signals (group propagate and group generate).
These signals used by the Look Ahead Logic Unit to determine the carries between the four blocks :C4,C8,C12,and C16 where Cout = C16.
The hierarchical organization reduces the dependence on sequential carry propagation compared with RCA.
### Hierarchical Structure 
### Level 1 --4-bit CLA blocks 
Each block calculates:
-four sum bits.
-Group propagate and group generate 
### Level 2 --Carry Look-Ahead Logic 
The higher-level logic uses the PG and GG signals to calculate the carries between the 4-bit blocks.
